# Tutorial: Environment & Path Configuration

This tutorial requires several pretrained resources and reference files to be available before execution.
Users need to download the required data and configure local paths accordingly.

This README explains what files are required, their expected roles, and how to configure paths in a reproducible way.

⸻

1. Base Directory

All tutorial data and outputs are organized under a single project root directory, referred to as BASE_DIR.

BASE_DIR = Path("/path/to/BrainBeacon/")

This directory is expected to contain:
	•	input data (e.g. AnnData objects)
	•	pretrained models
	•	prior knowledge resources
	•	downstream outputs generated by the tutorial

You should replace /path/to/BrainBeacon/ with your own local path.

⸻

2. Prior Knowledge and Pretrained Resources

Several pretrained and reference files are required and should be placed in a prior knowledge directory.

cfg.DEFAULT_PATHS["PRETRAIN_DIR"] = "/path/to/bb_PriorKnowledge/"
cfg.DEFAULT_PATHS["PRIOR_DIR"] = cfg.DEFAULT_PATHS["PRETRAIN_DIR"]

Only the file names below are fixed; their parent directory can be freely customized.

Required files

File name	Description
model_h5ad_1211.h5ad	Gene dictionary (AnnData), mapping gene IDs to symbols, homology groups, etc.
esm2_embeddings_d5120.pt	Precomputed ESM2 protein embeddings used by the model
stereo-seq_gene_nonzero_means_metacell_2.npy	Gene-wise non-zero mean expression statistics for normalization

Example configuration:

cfg.DEFAULT_PATHS["GENE_DICT_PATH"] = "/path/to/bb_PriorKnowledge/model_h5ad_1211.h5ad"
cfg_train["esm_embedding_path"] = "/path/to/bb_PriorKnowledge/esm2_embeddings_d5120.pt"

gene_mean_path = Path(
    "/path/to/bb_PriorKnowledge/stereo-seq_gene_nonzero_means_metacell_2.npy"
)

⸻

3. Input Data

The tutorial assumes a preprocessed AnnData object as input.

adata_path = BASE_DIR / "data" / "adata_outer_ensembl.h5ad"

Notes:
	•	The file name (adata_outer_ensembl.h5ad) is fixed in the tutorial.
	•	You may also use alternative inputs (e.g. adata_inner_ensembl.h5ad) as long as the schema is compatible.

⸻

4. Synchronizing Paths into the Configuration Object

The tutorial assumes that cfg and cfg_train objects already exist in the runtime (e.g. created earlier in the notebook or imported from the package).

cfg.DEFAULT_PATHS["BASE_DIR"] = str(BASE_DIR)

This allows all downstream modules to resolve paths consistently without hardcoding absolute locations.

⸻

5. Summary Checklist

Before running the tutorial, please ensure that:
	•	BASE_DIR points to your local BrainBeacon project directory
	•	The prior knowledge directory contains:
	•	model_h5ad_1211.h5ad
	•	esm2_embeddings_d5120.pt
	•	stereo-seq_gene_nonzero_means_metacell_2.npy
	•	The input adata_outer_ensembl.h5ad file exists under BASE_DIR/data/
	•	All paths in cfg.DEFAULT_PATHS and cfg_train are correctly set

Once these conditions are met, you can proceed with the tutorial notebooks or scripts without further path modification.
