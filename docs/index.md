# BrainBeacon

<p align="center">
  <img src="_static/graphical_abstract.png" alt="BrainBeacon graphical abstract" width="92%"/>
</p>

<p align="center"><b><i>
  🧠 A cross-species foundation model for single-cell–resolved brain spatial transcriptomics
</i></b></p>

BrainBeacon is a foundation model pretrained on large-scale brain spatial transcriptomics data across species and platforms.
It provides unified embeddings for downstream tasks such as cell type annotation, clustering, cross-species alignment, and in-silico perturbation.

```{note}
BrainBeacon is designed to support multi-species and multi-platform spatial transcriptomics analysis with a unified tokenization and modeling pipeline.
```
